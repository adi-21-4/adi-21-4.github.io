# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Hiring teams reviewing Aditya Joshi's engineering background and project work.

## Product Purpose

A personal portfolio that presents Aditya's software projects, work experience, education, skills, and writing so hiring teams can assess fit and follow up.

## Positioning

The portfolio spans full-stack product engineering and applied AI, supported by project repositories, a résumé, and documented work experience.

## Operating Context

Visitors read the page on desktop and mobile, browse project summaries, open source repositories, review the résumé, and use professional social links to connect.

## Capabilities and Constraints

The project is a static HTML, CSS, and JavaScript website. Preserve working navigation, project repository links, social links, and the résumé PDF. Primary audience: hiring teams. Keep factual claims grounded in the existing site and résumé; do not invent outcomes, customers, metrics, or testimonials.

## Evidence on Hand

- Project descriptions and repository links in `index.html`.
- Work history, education, and skills in `index.html` and `assets/Aditya_Joshi_Resume.pdf`.
- Writing entries in `index.html`.

## Product Principles

- Make engineering experience easy to assess quickly.
- Show the work and the implementation details behind it.
- Keep all claims traceable to the supplied portfolio or résumé.
- Keep the site readable and usable on small screens and with keyboard navigation.
